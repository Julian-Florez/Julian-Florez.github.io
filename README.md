# Portafolio de Julián Flórez

Sitio personal construido con Astro, React y Tailwind CSS. Presenta proyectos de Android, Linux, redes e inteligencia artificial, con tema terracota que sigue la preferencia claro/oscuro del sistema.

## Desarrollo local

```bash
npm ci
npm run check
npm run dev
```

## Publicación

El workflow de GitHub Actions compila y publica el sitio en [julian-florez.github.io](https://julian-florez.github.io/) al recibir cambios en `main`.
